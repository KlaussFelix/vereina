# vereina

**Ein Verwaltungs- und Organisationstool, das Vereinen die Arbeit abnimmt.**

## Worum geht es?

In Vereinen wird ein Großteil der Arbeit ehrenamtlich geleistet – neben Beruf, Familie und
anderen Verpflichtungen. Ein erheblicher Teil dieser wertvollen Zeit fließt jedoch nicht in das,
wofür sich die Menschen eigentlich engagieren, sondern in Verwaltung, Organisation und Planung:
Listen pflegen, Termine abstimmen, Informationen weitergeben, Aufgaben nachhalten.

**vereina** soll genau hier ansetzen. Das Ziel ist ein Werkzeug, das diese wiederkehrende und oft
lästige Arbeit so weit wie möglich vereinfacht, bündelt oder ganz abnimmt.

## Der Grundgedanke

> Je weniger Zeit Ehrenamtliche mit Verwaltung und Organisation verbringen müssen,
> desto gezielter können sie ihre Energie dort einsetzen, wo sie den Verein wirklich voranbringen.

Daraus ergeben sich die Leitlinien für das Projekt:

- **Entlasten statt belasten** – Jede Funktion muss Arbeit sparen, nicht zusätzliche erzeugen.
- **Einfach zu bedienen** – Ehrenamtliche haben unterschiedliche Vorkenntnisse; das Tool muss
  ohne Schulung verständlich sein.
- **Lästiges abgeben können** – Routineaufgaben sollen sich automatisieren oder unkompliziert an
  andere übergeben lassen.
- **Für Vereine gemacht** – Ausgerichtet auf die tatsächlichen Abläufe und Bedürfnisse von
  Vereinen, nicht auf die von Unternehmen.
